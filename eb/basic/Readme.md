## Create our rails project

## Install packages

```sh
bundle install
```

## Start our rails project

```sh
bundle exec rails s -b 0.0.0.0
```

## Create database

```sh
bundle exec rails db:create
```

## Migrate Database

```sh
bundle exec rails db:migrate
```
